# 🎨 AI Image Generator

An AI-powered image creation application developed using **Python, Streamlit, PyTorch, and Hugging Face Diffusers**. This project uses **Stable Diffusion 2.1** to generate high-quality images based on user-provided text prompts.

## ✨ Features

* 📝 Enter a descriptive text prompt
* 🎨 Generate images using artificial intelligence
* 🤖 Powered by Stable Diffusion 2.1
* 🖥️ Simple and interactive Streamlit interface
* ⚡ Generate creative images from natural language descriptions

## 🛠️ Technologies Used

* Python
* Streamlit
* PyTorch
* Hugging Face Diffusers
* Transformers
* Stable Diffusion

## 📦 Installation

### Step 1: Clone the Repository

```bash
git clone
cd AI-Image-Generator
```

### Step 2: Install Dependencies

Install all the required packages using:

```bash
pip install -r requirements.txt
```

## 🚀 Run the Application

Start the Streamlit application by running:

```bash
streamlit run imagegenerator.py
```

The application will start and open in your web browser.

## 🎯 How to Use

1. Launch the Streamlit application.
2. Enter your preferred image description in the prompt box.
3. Click the **Generate Image** button.
4. The Stable Diffusion model will process the given prompt.
5. The generated image will appear in the application.

## 💡 Example Prompt

```text
A cute cat sitting in a beautiful garden
```

You can enter any creative description and generate an image according to your prompt.

## 🤖 AI Model

This project uses the Hugging Face Stable Diffusion model:

```text
stabilityai/stable-diffusion-2-1-base
```

The model uses diffusion-based generative AI technology to convert text descriptions into images.
